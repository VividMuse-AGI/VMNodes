# MOSS 外部 JSON 按变化同步验收

日期：2026-10-30。v0.3.3 发布验收，增量基于 v0.3.2。

## 问题与修改

原行为已在本地 v0.3.2 后端复现：文本节点接入 `external_layout_json` 后，Replace 每次覆盖画布；Merge 每次更新导入框，因此拖动、改字等编辑会被旧 JSON 恢复。

新增 `On Change（仅外部 JSON 变化时同步）`，首次导入，之后比较最近一次成功应用的源内容。未变化时使用当前画布；发生变化时重新覆盖。比较忽略缩进、对象键顺序和代码围栏。同步记录写入 `layout_data` 并由前端保存，工作流刷新重开后仍有效，不进入模型提示词或 Draft 输出。

新建节点默认 On Change，已有工作流保留原选择，需手动切换。Replace / Merge / Ignore 保持原行为。若要强制重导同一份 JSON，使用 Replace 执行一次，再切回 On Change。单独连接 `global_prompt_in` 或 `box_texts_in` 时，这些文案端口仍按原逻辑覆盖对应文案。
