# VMNodes v0.3.0 · MOSS V2.3

## 中文

本次更新让 MOSS 排版的构图、长文案编辑和外部文本输入更方便，包含可直接导入的五框示例工作流。

- **构图参考线**：三分线和黄金分割线独立切换，在框体上方显示；开启吸附后可辅助拖动对齐，状态随工作流保存。
- **展开文字编辑**：图层行的 `⤢` 打开全宽多行抽屉。顶部全局描述也可拖高并保存高度。
- **外部文案连线**：`global_prompt_in` 接全局描述；`box_texts_in` 支持 `T1: 标题 | 样式`、角色/物体标签及按行顺序填入文字框。
- **修复**：执行回填后继续编辑抽屉时正确保存；全局描述拖高后不遮挡下一行；新建节点默认开启三分线，同时保留用户已保存的关闭设置。
- **示例与文档**：新增中英文快速开始、截图和无需模型的示例，仅依赖 VMNodes 与 ComfyUI 自带节点。

### 安装与使用

从本页 Assets 下载 **VMNodes-0.3.0.zip**，同名 **.zip.sha256** 提供校验值。解压后将 `VMNodes` 目录放到 `ComfyUI/custom_nodes/`，目录内应直接包含 `__init__.py`。更新前保存工作流，将旧目录备份到 `custom_nodes` 之外，避免重复加载或叠加旧文件。

使用 ComfyUI 自带 Python，在 ComfyUI 根目录运行：

```shell
python custom_nodes/VMNodes/install.py
```

重启 ComfyUI 并刷新页面。Git 安装可在没有本地修改的更新分支执行 `git pull --ff-only`。

将包内 `workflows/moss/MOSS-V2.3-Layout-Studio.json` 拖入 ComfyUI，点击运行即可看到布局预览和 JSON。也可[单独下载示例](https://raw.githubusercontent.com/VividMuse-AGI/VMNodes/v0.3.0/workflows/moss/MOSS-V2.3-Layout-Studio.json)。这是完整工作流，请勿粘贴到节点内部的“导入 JSON”弹窗。

**文案优先级**：保持 `box_texts_in` 连接时，每次执行都会采用上游文案，即使上游内容未变。若要保留抽屉里的手动改字，请断开该输入，或同步修改上游文本。非空 `global_prompt_in` 同样覆盖节点内的全局描述。

## English

This release adds MOSS V2.3 composition guides, a full-width text inspector, resizable global captions, and the `global_prompt_in` / `box_texts_in` ports. It fixes inspector edits being lost after execution backfill, caption resizing overlapping the next control, and the initial thirds-guide setting. Saved disabled guide settings remain intact.

Download **VMNodes-0.3.0.zip** and the optional **.zip.sha256** file from Assets. Back up the old package outside `custom_nodes`, extract the single `VMNodes` folder into `ComfyUI/custom_nodes/`, run `python custom_nodes/VMNodes/install.py` with ComfyUI's Python, then restart and refresh. Git users can run `git pull --ff-only` from a clean update branch.

Import `workflows/moss/MOSS-V2.3-Layout-Studio.json` from the package, or [download it separately](https://raw.githubusercontent.com/VividMuse-AGI/VMNodes/v0.3.0/workflows/moss/MOSS-V2.3-Layout-Studio.json). Drop the complete workflow onto ComfyUI, not into the layout node's Import JSON dialog. Run it to preview five boxes and the compiled JSON. It needs no models or additional custom node packs.

**Connected text takes precedence on every run.** Disconnect `box_texts_in` to retain manual inspector edits, or update the upstream text. A nonempty `global_prompt_in` likewise overrides the local caption.

Validation: **110/110** repository tests, including reproducible packaging, and **21/21** browser/API example checks against the extracted installation. The completed V2.3 audit also passed 146 browser, 136 MOSS frontend, 9 general frontend and 41 API checks. These suites overlap. Tested with ComfyUI 0.43.0 / frontend 1.57.4; no diffusion generation was performed. Native desktop eyedropper validation remains the historical V2.2 record.
