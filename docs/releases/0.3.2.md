# VMNodes v0.3.2 · MOSS 提示词补全 / Prompt autocomplete

## 中文

MOSS 区域描述现在可以使用 ComfyUI-Custom-Scripts 的英文候选词，不必在其他文本节点里选词后再复制过来。

- **适配范围**：图层行内描述与展开编辑区的“样式 / 画面描述”；角色、物体、文字样式均支持。实际海报文字仍按原样输入。
- **沿用现有习惯**：复用扩展的词库、分隔符、下划线替换和 Tab/Enter 设置；↑/↓ 选词，Tab/Enter 或点击插入，Esc 关闭。
- **编辑兼容**：中文输入法合成期间不误接收英文候选；切换区域、收起或删除节点时清理候选框；保留原生撤销和输入回退。
- **保留高度修复**：默认 12 行，手动高度随区域切换和工作流保存重载保留。

### 启用与词库

需要另行安装 [ComfyUI-Custom-Scripts](https://github.com/pythongosssss/ComfyUI-Custom-Scripts)，并启用其 **Text Autocomplete**。没有该扩展时 MOSS 仍可正常编辑。

1. ComfyUI 设置中搜索 `Autocomplete`，勾选 **Enabled**。
2. 点击 **Manage Custom Words**，在大文本框中每行一个词，例如下面三行。已有词库时追加，不要覆盖。

   ```text
   long_hair
   long_dress
   soft_lighting
   ```

3. 点击 **Save**，看到 **Saved!** 后回到 MOSS 区域描述框，输入 `long` 验证候选。

可勾选 **Replace _ with space**，把 `long_hair` 插入为 `long hair`；想保留 Enter 换行，可关闭 **Insert on Enter**、用 Tab 选词。词库匹配不等于 AI 续写或翻译，本更新不自动安装插件、下载词库或修改现有全局设置。

### 安装或更新

下载 Assets 中的 **VMNodes-0.3.2.zip** 与 **VMNodes-0.3.2.zip.sha256**。备份旧目录到 `custom_nodes` 外，将 ZIP 中的单个 `VMNodes` 文件夹放入 `ComfyUI/custom_nodes/`，使用 ComfyUI 的 Python 运行 `python custom_nodes/VMNodes/install.py`，重启并刷新页面。Git 安装可在干净的更新分支执行 `git pull --ff-only`。

## English

MOSS region descriptions now reuse optional ComfyUI-Custom-Scripts Text Autocomplete in layer rows and the expanded Style / Caption editor. Exact poster text stays literal.

- Reuses the extension's dictionaries, separators, underscore replacement and Tab/Enter settings. Select with ↑/↓, insert with Tab/Enter or a click, dismiss with Esc.
- Protects IME composition, removes stale popups when changing regions or removing nodes, and supports native undo and fallback insertion.
- Keeps twelve-row defaults and manually resized heights across region changes and saved workflow reloads. Editing remains available without the optional extension.

Install ComfyUI-Custom-Scripts, search Settings for **Autocomplete**, check **Enabled**, then open **Manage Custom Words**. Add one word per line (for example `long_hair`, `long_dress`, `soft_lighting`) and click **Save**. Append to existing words. Type `long` in a MOSS region caption to test. **Replace _ with space** is optional; disable **Insert on Enter** to keep Enter for newlines and use Tab to select. This is dictionary completion, not AI writing or translation. No dictionary or extension is installed automatically.

Download **VMNodes-0.3.2.zip** and its **.zip.sha256** checksum. Back up the old package outside `custom_nodes`, extract the single VMNodes folder, run its `install.py` with ComfyUI's Python, then restart and refresh. Git users can update a clean branch with `git pull --ff-only`.
