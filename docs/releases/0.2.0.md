# VMNodes v0.2.0 · Pre-release

## 中文

本次新增 **VM MOSS 海报布局工作台**，保留原有图像编辑、图像缩放节点及工作流接口。

- 在节点内编辑文字、人物和物体框，管理图层，导入或导出 Draft / Compiled JSON，输出 MOSS-Image 布局提示词。
- 支持中英文切换、17 组尺寸预设、鼠标滚轮缩放、中键／空格拖动、全部隐藏／显示。
- 支持全局和单框色板、原生系统吸管、画布放大镜吸管及参考图主色提取。
- 新增「总像素（MP）」设置：按当前画布比例换算尺寸，宽高对齐到 16，显示实际像素数。
- 新增 `Center Layout (居中扩展，缩小时整体适配)`：扩宽画布时保持前景框像素尺寸，整套布局与参考图居中；缩小时整体等比适配。
- 修复图层隐藏后列表跳顶、覆盖导入后旧缩放残留、Python 脚本误当 JSON、缩放后吸管错位和主色提取噪点过滤。

### 安装或更新

从本页 **Assets** 下载 `VMNodes-0.2.0.zip` 及可选的 `VMNodes-0.2.0.zip.sha256`。
解压后把其中的 `VMNodes` 文件夹放入 `ComfyUI/custom_nodes/`，不要多套一层目录。
更新前保存工作流并备份已有自定义修改；避免同时加载两份 VMNodes。

使用 ComfyUI 自己的 Python，在 ComfyUI 根目录运行：

```shell
python custom_nodes/VMNodes/install.py
```

重启 ComfyUI 并刷新页面，搜索 `MOSS` 添加节点。
Git 安装可在 VMNodes 目录执行 `git pull`；有本地修改时先处理或备份，避免覆盖。
详见 [MOSS 中文说明](https://github.com/VividMuse-AGI/VMNodes/blob/v0.2.0/docs/zh/nodes/moss-layout.md)。

### 扩宽海报的操作顺序

先覆盖导入原始 1152×2048 JSON，再选择 Center Layout，然后改为 1536×2048。
前景框整体右移 192 px，宽高和纵坐标不变；参考图两侧各留 192 px。
原稿已有重叠仍保留；参考留白不会自动补绘背景，切换模式也不会撤销旧模式已造成的放大。

## English

This release adds **VM MOSS Layout Studio**, preserving the existing image-edit and resize node contracts.
It includes bilingual in-node layout editing, JSON import/export, layer controls, zoom/pan, palettes,
native and canvas eyedroppers, reference palette extraction, megapixel sizing and Center Layout sync.
Layer scrolling, import framing, script-paste handling, pixel sampling and palette noise filtering are fixed.

Download `VMNodes-0.2.0.zip` from **Assets** and place its `VMNodes` folder directly under
`ComfyUI/custom_nodes/`. Back up custom changes, avoid duplicate installations, and run
`python custom_nodes/VMNodes/install.py` using ComfyUI's Python. Restart ComfyUI and refresh the browser.
Git installations can pull this update. See the [English guide](https://github.com/VividMuse-AGI/VMNodes/blob/v0.2.0/docs/en/nodes/moss-layout.md).

For centered expansion, import the original layout, select Center Layout, then resize the canvas.
Changing 1152×2048 to 1536×2048 shifts foregrounds 192 pixels to the right without enlarging them;
the reference image keeps matching side padding. Smaller canvases uniformly fit the whole layout.
Existing overlaps remain, padding is not outpainting, and switching modes does not undo prior resizing.

This is a Pre-release for Git or ZIP installation; no Registry publication is included.
Image generation still requires your own MOSS-Image workflow and model weights.
Existing edit and resize features remain at their previously published scope.
