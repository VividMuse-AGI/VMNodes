# VMNodes v0.1.7 · Pre-release

## 中文

VMNodes 是可持续扩展的 ComfyUI 节点包，本版提供：

- **VM 图像编辑**：按粗选范围、严格遮罩或整图编辑，预览范围，将结果回贴并输出 Final。
- **VM 图像缩放与对齐**：同步调整图像与遮罩，选择缩放算法及尺寸整除数。
- **Qwen Image 2.1 单图示例**：原版 8 步 LoRA，外接生成链，Final 已接到标准保存图像节点。

### 安装和开始使用

从本页 Assets 下载 `VMNodes-0.1.7.zip`，将其中的 `VMNodes` 文件夹放入 `ComfyUI/custom_nodes/`。使用 ComfyUI 自己的 Python，在 ComfyUI 根目录运行：

```shell
python custom_nodes/VMNodes/install.py
```

重启 ComfyUI 并刷新页面。单图示例还需要单独准备 4 个模型文件及 rgthree-comfy；按[中文快速开始](https://github.com/VividMuse-AGI/VMNodes/blob/v0.1.7/docs/zh/workflows/qwen-image-21-single-edit.md)导入示例、上传图片、画范围并填写需求。普通粗选、严格遮罩和整图编辑无需 SAM。

长期使用也可按 [README](https://github.com/VividMuse-AGI/VMNodes/blob/v0.1.7/README.md)通过 Git 安装，方便后续更新。ZIP 的 SHA-256 在同页 `VMNodes-0.1.7.zip.sha256` 中；GitHub 自动提供的 Source code 压缩包不是此安装资产。

### 升级与适用范围

从旧版升级前保存自己的工作流并备份旧包。从 0.1.6 或更早版本升级后，旧工作流需要连接 **VM 图像编辑 Final → 保存图像**，文件名前缀在保存节点设置。编辑节点中的预览是临时文件。

这是公开测试版。当前图像编辑支持 Qwen Image 2.1、一次一张主图、RGB 输出；复杂轮廓、新露皮肤、发丝与规则织纹交界仍可能出现残边或不自然过渡。范围内的细节取决于生成结果。反馈请附上版本、工作流和具体问题位置。

代码采用 MIT；模型权重不随包提供，遵循各自许可。Qwen Image 2.1 的商业使用要求见[模型许可](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE)。Registry / Manager 安装尚未验收，本版使用 Git 或 ZIP 安装。

## English

VMNodes is an extensible ComfyUI node package. This release includes:

- **VM Image Edit**: coarse-region, strict-mask and full-image editing, range previews and a composited Final output.
- **VM Image Resize & Align**: resize images and masks together, with selectable interpolation and dimension alignment.
- **Qwen Image 2.1 single-image example**: the original 8-step LoRA and an external generation chain, with Final connected to standard Save Image.

### Install and start

Download `VMNodes-0.1.7.zip` from this release's Assets. Place its `VMNodes` folder inside `ComfyUI/custom_nodes/`. From ComfyUI's directory, using its own Python, run:

```shell
python custom_nodes/VMNodes/install.py
```

Restart ComfyUI and refresh the page. The single-image example also needs four separately downloaded model files and rgthree-comfy. Follow the [English quickstart](https://github.com/VividMuse-AGI/VMNodes/blob/v0.1.7/docs/en/workflows/qwen-image-21-single-edit.md) to import the example, upload an image, draw a region and describe the change. Ordinary coarse-region, strict-mask and full-image edits need no SAM.

For convenient future updates, Git installation is also described in the [README](https://github.com/VividMuse-AGI/VMNodes/blob/v0.1.7/README.en.md). The matching SHA-256 is in `VMNodes-0.1.7.zip.sha256`; GitHub's automatic Source code archive is not this installation asset.

### Upgrading and scope

Save your workflows and back up the previous package before updating. Workflows from 0.1.6 or earlier need **VM Image Edit Final → Save Image**. Set the filename prefix on the save node. The editor's own preview is temporary.

This is a public test release. Image editing currently supports Qwen Image 2.1, one main image at a time and RGB output. Complex silhouettes, newly revealed skin, fine hair and patterned boundaries may retain artifacts or visible transitions. Generated details inside the region can change. Include your versions, workflow and the affected area when reporting problems.

The code is MIT-licensed. Model weights are not bundled and retain their own licenses; see [Qwen Image 2.1's terms](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE) for commercial use. Registry / Manager installation has not been accepted; use Git or ZIP for this release.
