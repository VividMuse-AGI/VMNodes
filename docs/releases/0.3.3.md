# VMNodes v0.3.3 · 保留布局编辑 / Preserve layout edits

## 中文

文本框连接「外部布局 JSON」后，手动移动框、改字再运行，以前会被原始 JSON 覆盖。新增 **On Change（仅外部 JSON 变化时同步）** 模式解决这个流程问题。

1. 更新后重启 ComfyUI，并按 **Ctrl+F5** 刷新页面。
2. **已有工作流务必手动将「外部同步方式」切换为 On Change**；新建节点默认使用此模式。旧工作流不会被自动改写。
3. 连接外部 JSON，先运行一次完成导入，再拖框、改字或增删框。以后重复运行保留画布编辑。
4. 上游 JSON 内容改变后，会重新覆盖画布。保存工作流、刷新重开后，同步记录仍保留。

仅改变 JSON 缩进、对象键顺序或 Markdown 代码围栏，不触发重新导入。同步记录不会写入模型提示词或 Draft 输出。

**模式区别：** Replace 仍每次覆盖；Merge 仍每次合并并更新导入框；Ignore 只使用画布。需要强制重新导入同一份 JSON，可临时切换 Replace 执行一次，再切回 On Change。单独连接的全局文案和各框文案端口仍按原规则覆盖对应文案。

**安装：** 下载 Assets 中的 `VMNodes-0.3.3.zip`，同名 `.zip.sha256` 提供校验值。先将旧目录备份到 `custom_nodes` 之外，再将 ZIP 内的单个 `VMNodes` 文件夹放入 `ComfyUI/custom_nodes/`；使用 ComfyUI 的 Python 运行 `python custom_nodes/VMNodes/install.py`，重启并刷新页面。Git 安装可在干净分支执行 `git pull --ff-only`。

**验证：** Python **120/120**；MOSS 前端 **140/140**；通用前端 **9/9**；补全单元 **10/10**。既有浏览器验收 **151/151**，新增外部同步浏览器检查 **10/10**，覆盖真实文本节点连线、API 执行回填、鼠标拖框、改字、保存后刷新重开、上游变化及清空后重跑。使用隔离 CPU 服务验证布局，不将结果表述为模型生图质量测试。

## English

Connecting a text node to External Layout JSON used to reset manually moved boxes and edited text on every run. The new **On Change** sync mode preserves these edits until the source JSON changes.

1. Restart ComfyUI and hard-refresh the browser after updating.
2. **Select On Change manually in existing workflows.** New nodes use it by default; saved workflows keep their existing mode.
3. Run once to import the connected JSON, then move, resize, edit, add or delete boxes. Repeated executions preserve those edits.
4. Changed upstream content replaces the canvas. Import history survives workflow saves, page refreshes and reopening.

Indentation, object key order and Markdown fences do not trigger reimport. Import history is kept out of model prompts and Draft output.

**Legacy behavior remains:** Replace always overwrites; Merge always merges and updates imported boxes; Ignore uses the canvas only. For a forced reimport, run once with Replace and return to On Change. Separate global-caption and box-text inputs retain their existing text override behavior.

Download `VMNodes-0.3.3.zip` and its `.sha256` from Assets. Back up the old directory outside `custom_nodes`, extract the single `VMNodes` folder into `ComfyUI/custom_nodes/`, run `install.py` with ComfyUI's Python, restart and refresh. Clean Git installations can use `git pull --ff-only`.

Validation: **120 Python**, **140 MOSS frontend**, **9 general frontend**, **10 autocomplete unit**, **151 existing browser** and **10 new external-sync browser checks**, all passed. Browser tests exercise actual API execution and editor backfill on an isolated CPU service; they do not assess generated-image quality.
