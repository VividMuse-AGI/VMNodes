# VMNodes v0.3.1 · 编辑区高度修复 / Inspector height fix

## 中文

本次修复 MOSS 区域展开编辑区太矮、切换区域后手动高度丢失的问题。

- **默认各 12 行**：文字框的“渲染文字”和“样式/画面描述”均提供更大的输入空间；人物和物体框的描述字段同样为 12 行。
- **记住手动高度**：两个字段的高度分别保存，切换区域、收起再展开、保存工作流后重载均保留。同一节点的新区域沿用该字段的高度偏好。
- **布局同步**：拖高输入框时节点同步增高，收起抽屉后恢复；高度只保存在节点属性，不改变 `layout_prompt` 或 `draft_json`。

### 安装或更新

下载本页 Assets 中的 **VMNodes-0.3.1.zip**，可使用 **VMNodes-0.3.1.zip.sha256** 校验。把旧目录备份到 `custom_nodes` 之外，再将 ZIP 中的 `VMNodes` 文件夹放入 `ComfyUI/custom_nodes/`。避免重复加载两份 VMNodes，不要叠加旧文件。

使用 ComfyUI 自带 Python 运行 `python custom_nodes/VMNodes/install.py`，然后重启 ComfyUI 并刷新页面。Git 安装可在没有本地修改的更新分支执行 `git pull --ff-only`。

包内示例位于 `workflows/moss/MOSS-V2.3-Layout-Studio.json`；也可[单独下载](https://raw.githubusercontent.com/VividMuse-AGI/VMNodes/v0.3.1/workflows/moss/MOSS-V2.3-Layout-Studio.json)。它只依赖 VMNodes 和 ComfyUI 自带节点，无需模型。

### 验证与边界

发布源码通过全仓 **110/110**、MOSS 前端 **139/139**；从安装包解压启动 ComfyUI 后，完整浏览器 **151/151**、示例浏览器/API **21/21**。用真实鼠标将描述框从约 219px 拉到 349px，切换区域、重新展开及保存重载后保持一致；默认两个输入框均可显示 12 行。

套件有重叠，不相加为独立测试总数。实测环境为 ComfyUI 0.43.0 / 前端 1.57.4。本次没有运行扩散模型生成图片。

`box_texts_in` 的覆盖规则不变：连线时每次运行均以外部文案为准。想保留抽屉里的手动改字，先断开该连线，或同步修改上游文本。

## English

This patch fixes cramped region inspectors and heights resetting when switching boxes.

- **12 rows by default** for Exact Text and Style / Caption, including character and object descriptions.
- **Independent saved heights** for text and caption fields, shared across regions within a node and retained when reopening the drawer or reloading a saved workflow.
- The node grows with resized inputs and contracts when the drawer closes. Height preferences stay in node properties and do not alter layout prompts or Draft JSON.

Download **VMNodes-0.3.1.zip** and the optional **.zip.sha256** checksum from Assets. Back up the old directory outside `custom_nodes`, extract the single `VMNodes` folder to `ComfyUI/custom_nodes/`, run `python custom_nodes/VMNodes/install.py` using ComfyUI's Python, then restart and refresh. Git users can run `git pull --ff-only` from a clean update branch.

The bundled [model-free example](https://raw.githubusercontent.com/VividMuse-AGI/VMNodes/v0.3.1/workflows/moss/MOSS-V2.3-Layout-Studio.json) can be dropped directly onto ComfyUI.

Validation: **110/110** repository tests and **139/139** MOSS frontend checks; **151/151** full browser checks and **21/21** example browser/API checks against an extracted installation. These suites overlap. Tested on ComfyUI 0.43.0 / frontend 1.57.4, without diffusion generation.

Text precedence is unchanged: connected `box_texts_in` overwrites matching local fields on each run. Disconnect it to retain manual edits, or update the upstream text.
