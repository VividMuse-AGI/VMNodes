# 使用示例与效果边界

[返回首页](../../README.md) · [节点使用说明](nodes/image-edit.md) · [English](../en/editing-examples.md)

日常局部编辑从“按粗选范围”开始，粗圈完整旧目标，填写需求后运行。圈选不需要精确描边；如果结果有残留，先用“仅预览范围”检查是否漏选，不要连续扩大范围或反复切换选项。

## 示例：长裙改短裙

> 将灰色长裙改为灰色膝上 A 字短裙，保持人物、站姿、上衣、鞋子和背景，露出的腿部与原有光照一致。

把旧裙摆和需要补出腿部、背景的位置包含在范围内。这类编辑已有人工认为够用的结果，但并非每张图都能成功。重点检查双腿与膝盖、裙摆、皮肤过渡和地板投影。

## 示例：宽松上衣收窄

> 将宽松的深蓝色上衣改为合身款，保持人物体型、坐姿、双手和裤子，自然补全原衣服挡住的沙发。

范围要包含旧衣服轮廓，不能只圈想要的新轮廓。已有案例完成了收窄，但手边仍留下小块旧衣料。切换为“严格按所画遮罩”也没有完全解决；不应把这种结果当作已修复。

若残片在范围外，节点会保留它。若衣服与手、发丝或规则纹理紧贴，增加范围可能同时改到这些部位；节点目前不能保证自动找到既完整去除旧物、又无损保留邻近内容的边界。

## 哪些效果需要重点检查

| 编辑情况 | 检查什么 |
|---|---|
| 换装或缩短衣物，新露出皮肤 | 肤色、质感和肢体轮廓是否接得自然 |
| 换发型或改发色 | 发梢、额前和肩部有没有漏改，邻近衣料是否变化 |
| 沙发或物品换材质 | 遮挡物周边有无旧材质残圈，阴影是否完整更新 |
| 整图编辑 | 脸部、背景和原本无需修改的细节是否被一起改变 |

这些是当前仍可能遇到的效果限制，不是需要额外安装模型或开启隐藏参数的提示。先看整图与原尺寸是否满足用途；本节点不保证复杂边界自动无痕。

## 选择最少的必要功能

- 只调整尺寸：单独使用“VM 图像缩放与对齐”。
- 普通局部编辑：一张主图、一个粗选范围、一段编辑需求；参考图、保护遮罩和接缝协调按需使用。
- 要求保留某区域原像素：使用保护遮罩，但仍要检查保护区与新内容的接缝。
- 接受周围内容一起变化：可以选择整图编辑；它不是局部失败后的自动修复保证。

当前编辑一次处理一张主图，支持额外内容参考图，输出为 RGB，配合 Qwen Image 2.1 使用。参考图不等于批量或多主图编辑；其他模型与透明编辑不在当前支持范围内。
