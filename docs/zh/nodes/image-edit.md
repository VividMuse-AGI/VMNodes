# VM 图像编辑

[返回首页](../../../README.md) · [English](../../en/nodes/image-edit.md)

推荐先使用 [Qwen Image 2.1 单图编辑示例](../../../workflows/image_edit/Qwen-Image-2.1-Single-Image-Edit.json)。按[单图编辑快速开始](../workflows/qwen-image-21-single-edit.md)安装依赖、选择模型，上传一张主图后运行。

默认单图示例使用外接生成节点，已接好单图编辑和保存。下文“可选功能”中的参考图、保护遮罩开关属于[原统一编辑示例](../../../workflows/image_edit/VM_图像编辑.json)；默认单图示例没有这些开关和对应图片加载器。

## 模型准备

默认单图示例需要 Qwen Image 2.1、对应文本编码器、VAE 和 8 步加速 LoRA 共 4 个文件，路径与下载入口见[快速开始](../workflows/qwen-image-21-single-edit.md)。在工作流中选择实际文件；模型文件不包含在节点包中。还需安装 [rgthree-comfy](https://github.com/rgthree/rgthree-comfy)，以保留示例中的图像对比与分组控制节点。需要支持该模型的 ComfyUI 版本；旧版 ComfyUI 缺少相应官方节点时需先更新主机。

Qwen Image 2.1 使用 [Qwen Research License](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE)，商业使用需另行取得模型许可；VMNodes 的 MIT 许可证不覆盖模型。

普通编辑无需 SAM。默认单图示例保留 SAM 加载器，但没有接入编辑节点。只有“细化到物体”需要按[快速开始中的接线说明](../workflows/qwen-image-21-single-edit.md#可选细化到物体)接入 SAM；该路线中的整个人物独立校验还需要[模型清单](../../models.json)中的人员检测模型和可选依赖。用 ComfyUI 的 Python，在 ComfyUI 根目录执行：

```shell
python custom_nodes/VMNodes/install.py --person-check
```

安装可选依赖后重启；其他编辑模式不必安装它。依赖和模型遵循各自授权。
如果安装程序提示缺少其他依赖，先在 ComfyUI 环境中补齐所提示的组件；程序不会为此自动替换现有 OpenCV 或 PyTorch。

“细化到物体”是可选路线，已有实际预览验证，但并非所有物体都能可靠识别。遇到“独立检测未确认人物”表示自动识别证据不足，不是图像尺寸错误；可以主动切换为“按粗选范围”。节点不会为继续生成而自动绕过检查。日常使用建议先选“按粗选范围”或“严格按所画遮罩”。

## 第一次使用

### 只修改图片的一部分

1. 在工作流左侧上传图片。
2. 右键图片，打开 **Mask Editor**，粗圈需要修改的区域，保存遮罩。
3. 在 **VM 图像编辑 → 编辑需求**中写下希望怎样修改。
4. 保持 **按粗选范围**和 **直接生成**，点击 ComfyUI 的运行按钮。

例如：

> 将上衣改为深红色，保留款式、织纹和原有光照。

粗圈不用精确描边，但应尽量闭合，并包含完整目标。删除物品时把阴影一起圈进去；替换更大的物体时，为新轮廓留出空间。

缩短裙摆或收窄衣服时，把旧轮廓和需要补出的背景都包含在范围内。只圈新轮廓会留下旧衣料；预览时特别检查手边、袖口和遮挡交界。

圈内一起包含的衣服、皮肤或背景也可能被重新生成。先完整覆盖目标，不必一律继续外扩，也不必默认添加保护图。规则织纹或细发丝交界仍可能变化，当前不保证自动保留圈内所有无关细节。

### 不画遮罩，直接编辑

上传图片，将“选区方式”改为 **整图编辑（无需遮罩）**，填写需求后运行即可。已有遮罩不用删除，切回局部编辑时还可以继续使用。

例如：

> 将披发改为自然的高马尾，保持原有发色，自然补全露出的衣服。

整图编辑适合希望模型一起调整周围内容的情况，但脸部、衣服纹理和背景也可能有细微变化。想限制修改位置时，使用局部编辑。

## 保存或继续处理结果

将 **VM 图像编辑的 Final → 保存图像（Save Image）**。示例工作流已接好，默认保存在 ComfyUI 的 `output/VMNodes` 文件夹；子目录和文件名前缀在“保存图像”节点里修改。

编辑节点中的预览是临时文件，不会自动保存到 `output`。只想查看结果时，可不接保存节点，或将 Final 接到“预览图像”；还可以先接其他图像处理节点，处理完再保存。

“仅预览范围”不向 Final 输出图片，因此示例中的保存节点不会把绿色、蓝色遮罩图存成最终结果。需要单独保存范围图时，可主动把“范围预览”接到另一保存节点。

仅预览范围时，保存节点可能仍显示上次的图片；这不表示本次保存了新的 Final。

## VM 图像编辑：每个选项有什么用

### 选区方式

| 选项 | 作用 | 什么时候用 |
|---|---|---|
| **按粗选范围** | 把闭合轮廓内部作为允许编辑的范围 | 日常局部编辑，推荐从这里开始 |
| **整图编辑（无需遮罩）** | 根据需求编辑整张图片，不需要画范围 | 换发型、补全被遮挡的内容，或不想画遮罩时 |
| **严格按所画遮罩** | 只编辑实际涂过的位置 | 小范围修补；要修改整块区域就填满，不要只画空心圈 |
| **细化到物体** | 在粗选附近识别物体，让选区更贴近轮廓 | 希望自动贴合物体边缘时；需要 SAM 模型，建议先预览 |

### 常用设置

| 设置 | 作用与用法 |
|---|---|
| **编辑需求** | 描述“改哪里、改成什么、希望保留什么”，不需要固定句式 |
| **执行方式 → 直接生成** | 生成编辑后的图片 |
| **执行方式 → 仅预览范围** | 先查看选区，不生成编辑结果；确认后切回“直接生成”再运行 |
| **展开预览 / 收起预览** | 打开或关闭独立结果查看面板；按钮本身不会重新运行 |
| **接缝协调 → 自动** | 尝试减轻局部编辑边缘的轻微色差；通常先保持关闭，整图模式无需使用 |
| **语言** | 自动跟随 ComfyUI，或固定为中文、English；不翻译你填写的需求 |

**范围预览怎么看？** 绿色表示可以修改，蓝色表示受到保护。整图模式的边框表示整张图片可编辑，并不是对实际修改位置的预测。修改选项后，需要再次运行才能更新预览。

自动协调不保证消除换装或新显露表面的色差。“已尝试局部协调”表示处理了部分像素，仍需查看实际接缝。

### 可选功能（原统一编辑示例）

以下开关适用于[原统一编辑示例](../../../workflows/image_edit/VM_图像编辑.json)。默认单图示例采用手动外接生成链，没有这些开关及对应图片加载器；如需这些功能，可导入原统一示例。使用统一示例时，不需要参考图或保护区域就保持关闭。

| 功能 | 用途 | 怎么用 |
|---|---|---|
| **内容参考图** | 参考另一张图中的物品、材质或外观 | 在“参考方式”中选择它，在下方对应节点上传参考图，并说明参考什么 |
| **启用保护遮罩** | 保留不希望变化的区域，例如脸部或文字 | 在保护图节点加载同一张主图，清空已有遮罩，画出要保留的区域 |
| **遮罩引导（实验）** | 给模型额外的范围提示 | 可尝试用于局部编辑；不能保证改善效果，不支持整图模式 |

参考图需求示例：

> 图1是主图，将桌上的花瓶替换为图2中的花瓶，匹配图1的光照。图2只参考花瓶外观。

保护区优先于编辑区。只在需求里写“保持脸不变”不能保证完全不变；需要保留原像素时，请使用保护遮罩。保护区与新内容的交界仍可能出现接缝。

## 常见问题

**提示遮罩为空怎么办？** 需要局部编辑时，在主图上画好范围并保存；不想画遮罩时，明确选择“整图编辑（无需遮罩）”。

**编辑后还有旧颜色、发丝或阴影残留？** 先预览范围，检查是否遗漏旧目标或阴影。范围外的内容会保留原样，切换选区模式或接缝协调不能补上漏选。若旧目标紧贴手部、发丝或织纹，完整覆盖后也可能出现残边或接缝；不要为清除残片无限扩大范围。整图编辑允许周围一起变化，但不保证更好。见[使用示例与效果边界](../editing-examples.md)。

**严格按所画遮罩一定更干净吗？** 不一定。它只使用实际填涂的位置，不会把空心圈内部当作整块选区，也不负责清除范围外的残片。按需要选择模式，不要把切换模式当作通用边缘修复。

**为什么选区外的脸或背景也变了？** 整图模式允许全图调整。希望限制改动时改用局部模式；需要额外保护遮罩时，按上面的原统一示例操作。

**能一次编辑多张主图吗？** 当前一次处理一张主图。原统一示例可额外提供一张内容参考图；默认单图示例没有预接内容参考。多张主图请分别运行。

**支持透明图片编辑吗？** 当前编辑结果为 RGB，不保留透明输出。需要透明背景时，不应把本节点当作完整的 RGBA 编辑流程；独立缩放节点可保留输入图像的第四通道。

**切换接缝协调会重新生成吗？** 上游输入不变且缓存仍可用时，可以复用生成结果。修改提示词、种子等上游设置，或重启、缓存失效后，可能需要重新生成。

**如何找节点或恢复工作流？** 搜索 `VMNodes` 即可找到节点。通过标准“保存图像”保存且包含工作流信息的 PNG，可以拖回 ComfyUI 恢复工作流。请勿关闭 ComfyUI 的图片元数据；原图、参考图和模型仍需保留。
