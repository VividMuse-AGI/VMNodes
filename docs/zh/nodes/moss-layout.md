# VM MOSS 海报布局工作台

[返回首页](../../../README.md) · [English](../../en/nodes/moss-layout.md)

在节点内部直接画框排版，输出 MOSS-Image 需要的布局提示词；同时可以把
`moss-image-prompt-enhancer` Skill 生成的 JSON 一键导回画布继续微调。

不需要生成模型即可使用；接上 MOSS-Image 的 `CLIPTextEncode` 后才会真正出图。

## 快速开始

1. 添加 **VM MOSS 海报布局工作台**（搜索 `MOSS`、`海报`、`layout`）。
2. 选尺寸预设，或在 `Custom` 下手填宽高（会自动对齐到 16 的倍数）。
3. 点 `+ 文字框 / + 角色框 / + 物体框`，或双击画布空白处新建文字框。
4. 写「全局描述」，在图层列表里填文字与样式/画面描述。
5. `layout_prompt` 接 `CLIPTextEncode`（MOSS），`width/height` 接 `EmptyLatentImage`，
   `preview_image` 接 `预览图像`。

> 运行前请关闭 **Prompt Upsampler**：布局 JSON 是机器可读结构，扩写会破坏它。

## 端口

| 输入 | 说明 |
|---|---|
| `ui_language` | `中文 (ZH)` / `English (EN)`，同时驱动顶部 `[中文 \| EN]` 开关 |
| `canvas_preset` | 尺寸预设，`Custom` 时使用下面的宽高 |
| `width` / `height` | 自定义宽高；输出前统一对齐到 16 的倍数 |
| `bbox_ratio_sync` | 改画布比例时框体如何同步：`Smart` / `Keep Box Aspect` / `Stretch` / `Center Layout` |
| `scene_meta` | 体裁先验，写入 `summary.meta` 的第一项；`none` 表示不写 meta |
| `canvas_layout_type` | `single` / `multi_panel` / `collage`，写入 `summary.canvas` |
| `layer_order_mode` | `Auto`（背景→物体→角色→文字置顶）/ `Manual`（严格按列表） |
| `global_prompt` | 全局画面描述，写入 `summary.caption` |
| `layout_data` | 画布状态（前端自动维护） |
| `ref_image`（可选） | 参考底图，显示在画布中并对齐比例，不进入提示词 |
| `external_layout_json`（可选） | 连线输入 Skill Draft / 编译后 JSON / 纯 caption |
| `external_sync_mode`（可选） | `Ignore` / `Replace Canvas`（覆盖画布并回填）/ `Merge into Canvas`（追加并回填） |
| `custom_meta_tags`（可选） | 追加体裁标签，逗号分隔，自动合入 `summary.meta` |

| 输出 | 说明 |
|---|---|
| `layout_prompt` | 模型输入格式（`abs_centralized` + `yxyx` 紧凑 JSON）；无有效框时输出纯 caption |
| `draft_json` | 草稿格式（`abs` + `xyxy` 可读 JSON），可直接粘回 Skill |
| `preview_image` | 带图层配色、`T1/C1/O1` 编号、层级与文字的预览图 |
| `width` / `height` | 对齐后的最终像素宽高 |

## 尺寸预设

竖版海报 3:4 / 2:3、手机 9:16、长图信息图 1:2、A4 印刷比例、方形 1:1、
横版 4:3 / 3:2 / 16:9 与 21:9，每类都提供标准与高清两档。设计文档正文写「16 组」，
但其清单实际列出 17 组（横版多一组 `Ultrawide 21:9`），本节点按清单全部实现。

所有预设宽高都是 16 的倍数；手动输入的宽高会被就近对齐（如 `1001×777` → `1008×784`），
`width` / `height` 输出与 `bbox` 使用同一个画布尺寸；预览图按比例缩小，长边最多 1152 像素。

### 按总像素调整

在工具栏下的「总像素（MP）」填写目标，点击「应用」或按 Enter。`1 MP = 100万像素`，
`2 MP = 200万像素`。按当前画布宽高比换算，宽高就近对齐到 16，因此实际像素数会略有偏差，
右侧显示实际尺寸和 MP。例如 1152×2048 设为 2 MP，得到 1056×1888（约 1.994 MP）。

应用后尺寸预设变为 Custom，框沿用「比例同步」设置调整。先选预设比例或导入 JSON，
再应用所需 MP 即可。目标值随工作流保存；之后修改预设或覆盖导入 JSON 会采用新的源尺寸，
需要时再次点「应用」。宽高由连线提供时此控件禁用。

输入范围为 0.01～32 MP；换算后的每边仍须在 256～4096 内，超出时提示且保留原布局。
这是编辑画布的尺寸快捷操作；实际生成尺寸仍通过节点 `width/height` 输出连接潜空间节点。

### 居中扩展同步模式

「比例同步」新增 `Center Layout (居中扩展，缩小时整体适配)`。

1. 先导入原始布局，例如 1152×2048。若旧模式已经放大过框，请重新覆盖导入原稿。
2. 选择上述同步模式，再修改画布尺寸。
3. 1152×2048 → 1536×2048 时，人物、文字和装饰的宽高、纵坐标不变，横坐标统一增加 192 px。
   参考底图也保持原显示大小并居中，左右各留下 192 px；后端预览使用相同位置。

原本铺满画布的物体框继续铺满：判定为宽、高均至少占 98%，且中心在画布中心附近 1% 内。
其他大物体仍作为前景统一移动。缩小画布时，整套布局和参考底图按同一倍率等比缩小居中，
避免逐框挤压或裁掉边缘。该模式对锁定和未锁定的前景框采用相同的整体变换。

参考图位置随工作流保存；「覆盖画布」导入建立新的对位基准。切换模式本身不恢复旧框尺寸，
缩小后再扩展也不会自动放大回原尺寸，需要时重新导入原稿。
左右留白是参考预览，不会自动生成背景像素；实际扩图需要另接图像处理流程。
本模式保留原有相对位置，因此原稿中已有的重叠仍需手动调整。

## 体裁与画布结构

`summary.meta` 是媒介/体裁标签数组，用来激活排版先验：`poster`、`infographic`、
`product campaign`、`editorial`、`comic`、`illustration`、`photography`、`ui_design`。
需要多个标签时用 `custom_meta_tags` 追加。

`summary.canvas` 决定画布组织方式：

- `single`：单幅完整画面，普通海报默认。
- `multi_panel`：多格分栏 / 多模块卡片，做信息图、对比图、分格漫画时使用。
- `collage`：拼贴画布局。

## 画布操作

- 拖动框体移动，拖角点缩放；`Delete` 删除，方向键微调（`Shift` 加速）。
- 工具栏：网格吸附、水平/垂直居中、等宽、等高、水平/垂直等距、全部隐藏/显示。
  等宽/等高以**选中的框**为基准；开启 `🔒` 的框会按自身比例同步另一边。
- 图层列表：`☰` 拖动调整层级，`👁` 临时隐藏（不进入输出），`🔒` 锁定比例，
  类型下拉切换 `文字 / 角色 / 物体`，行内直接改文字与描述。
- `Auto` 模式下，画布绘制顺序、鼠标命中顺序与最终输出顺序完全一致：文字永远置顶，
  背景面积大的先画。`T1/C1/O1` 编号跟随列表顺序，不随排序变化，方便核对。
- 在原有比例同步模式下，改画布比例时锁定框与文字/角色保持物理比例；`≥70%` 面积的大背景在 `Smart`
  模式下铺满画布。

## 缩放、显隐与调色盘（V2.1）

### 画布缩放与平移

- 鼠标悬停在节点画布上滚动滚轮：以**光标位置为锚点**在 `100% ~ 600%` 之间无级缩放。
  滚轮事件被节点完全接管（`preventDefault` + `stopImmediatePropagation`），
  外层 ComfyUI 节点图不会跟着缩放。
- 按住**鼠标中键**（滚轮键）拖动平移；笔记本可用 **空格 + 左键** 拖动。
  中键默认的浏览器自动滚屏与画布平移同样被阻止。
- 缩放后画框命中、拖动、角点缩放、双击新建全部按 `1 / zoom` 反算，与 100% 完全一致；
  线宽、角点手柄与标签文字按 `1 / zoom` 反向补偿，放大到 600% 依然清晰。
- 右上角出现 `🔍 240% ↺` 徽章：点击徽章、按 `0` 或双击中键即可回到 100% 居中视图。

### 一键隐藏 / 显示全部框

工具栏 `👁 全部隐藏` 会把所有框设为不可见（编译结果自动退化为纯 `global_prompt` 文本），
按钮随即变为高亮的 `🚫 全部显示`，再点一次全部恢复。空画布时按钮自动禁用。

### 可视化调色盘

- **全局色板**（工具栏下一行，写入 `summary.palette`）：5 套预设配色主题
  （科技深蓝霓虹 / 黑金奢华海报 / 极简奶油杂志 / 国风朱砂墨色 / 清新生态信息图），
  可用取色器 `🎨+` 追加任意主色，点色块上的 `×` 移除。
- **单框色板**（图层行 `🎨` 按钮，写入 `item.palette`，最多 4 色）：16 色海报快选色盘、
  `<input type="color">` 自由取色、以及 `#FF5733` / `ivory` 这类色值或颜色词手输。
  已选颜色会以圆点显示在图层行与画布框标签旁。
- 后端 `preview_image` 同步绘制全局色板（底部状态栏右侧）与单框色点（标签右侧）。

## 吸管取色与参考图提取配色（V2.2）

### 三级联动拾色

| 入口 | 行为 |
|---|---|
| 全局色板栏 `💧 吸管` | 优先调用浏览器原生 `window.EyeDropper`，可吸取屏幕任意位置（含其他窗口）的颜色并加入 `summary.palette` |
| 单框调色盘 `💧 吸管取色` | 同上，但写入该框的 `item.palette`（上限 4 色） |
| 画布吸管模式（降级） | 当环境不支持 EyeDropper（Firefox / Safari / 非 HTTPS 局域网 IP）时自动进入；也可在画布聚焦时按快捷键 `I` 直接进入 |

画布吸管模式的细节：

- 目标自动判定：有选中框时写入该框色板，无选中框时写入全局色板。
- 鼠标移动时从参考底图的独立离屏缓存读取像素（不含选框叠加色），实时绘制十字准线、
  圆形色彩预览环与 `#RRGGBB` 胶囊；胶囊在靠近右边缘时会自动翻到左侧。
- 参考图采样会逆算内部缩放和平移；无参考图时读取已渲染画布，但排除吸管自身的圆环、准线和色值胶囊。
- 左键单击确认并退出；`Esc` 或右键取消。按 `Esc` 取消原生吸管时不会写入任何颜色，也不会报错。

### 参考图一键提取配色

接入 `ref_image` 并运行一次后，参考图栏与全局色板栏都会出现 `🎨 提取配色`：

- 把参考图缩到 `48×48` 读取像素，按每通道 4 bit（4096 桶）统计直方图，桶内取真实 RGB 均值；
- 按像素占比从高到低挑选，要求候选色与已选色在 RGB 空间的距离 ≥ 42，保证 4 个颜色视觉可分；
- 过滤透明像素（alpha < 128）、极白（RGB 三通道均 ≥ 250）和极黑（RGB 三通道均 ≤ 5）；普通浅色、深色和饱和色保留；
- 纯色或低对比图片不足 4 色时从剩余有效色桶补充，最多 4 色，不凭空生成颜色；全部被过滤时保留原色板并提示无法提取；
- 结果直接替换全局色板 `S.state.palette`，状态栏右侧给出「已提取 N 个主色」提示。

## 导入与导出 Skill JSON

两条途径：

1. **画布工具栏** `📥 导入 JSON`：粘贴后立即回填画布、图层列表、全局描述、体裁与画布结构；
   可选择「覆盖画布」或「追加到画布」。
2. **连线 `external_layout_json`**：由 LLM / Skill 节点输出 JSON，运行后把解析结果通过
   `onExecuted` 回填到画布（`Replace` 覆盖、`Merge` 追加），修改上游后再运行即可刷新。

支持三种格式，自动识别：

- Draft（`bbox_coord_space: "abs"` + `bbox_format: "xyxy"`，左上角像素坐标）
- 编译后（`abs_centralized` + `yxyx`，中心原点像素坐标）
- 纯 caption：`{"caption": "..."}` 或普通字符串

其他细节：

- 自动剥离 ` ```json ` 代码块。
- 跨尺寸导入时，先用**源画布尺寸**算出物理比例，再按当前 `bbox_ratio_sync` 同步到目标画布，
  不会因为直接套用归一化宽高而拉长压扁。
- 每个导入框使用内容哈希 ID，重复运行或重复导入不会产生重复框。
- `📤 导出 Draft` 生成的 JSON 与官方 `compile_prompt.py` 的草稿格式一致，可粘贴回 Skill
  或任意 LLM 继续迭代；再把结果导入回来即可继续微调。

## 语言

顶部 `[中文 | EN]` 开关与 `ui_language` 双向联动：工具栏、图层类别、占位符、状态栏、
导入导出弹窗与节点标题会立即切换，无需刷新。下拉框的**选项值**保持中英固定写法，
以免切换语言破坏已保存的工作流；`locales/zh`、`locales/en` 同时提供节点显示名翻译，
跟随 ComfyUI 语言设置。

## 从旧版迁移

旧版 `MOSSLayoutStudio` 使用 `MOSS_BBOX` 端口传递布局。V2 已移除该端口，改用
`external_layout_json`：

- 旧的框布局若还在 `layout_data` 里，可直接继续使用（状态版本向后兼容）。
- 需要跨节点传模板时，把上游输出转成 Draft JSON 文本再接 `external_layout_json`，
  或在画布中 `📤 导出 Draft` 保存为文件后再导入。

## 已知限制

- 预览图长边上限 1152px，图中文字是排版示意，不代表最终字体。
- `draft_json` 中若某个文字框没有填写渲染文字，会输出空 `text`；官方 `compile_prompt.py`
  要求文字框必须有非空 `text`，请补全后再交给 Skill（状态栏会提示缺少文字的数量）。
- `bbox` 使用官方编译器的「向外包络」取整：左/上取 `floor`，右/下取 `ceil`，
  因此同一归一化框在不同画布上可能相差 1px。
- `--lowvram` 或极小显存下预览图生成会增加少量内存占用（与画布尺寸无关，长边固定）。

## 常见问题

**画布没变但输出尺寸变了？** 检查 `canvas_preset` 与 `width/height` 是否一致；
连线驱动尺寸时，前端会在运行后自动把预设切到 `Custom` 并显示实际分辨率。

**导入 JSON 没反应？** 确认顶层有 `items` 数组，或只有 `caption`；确认 `bbox` 是四个数字。
若提示无法识别，可先去掉外层说明文字，只保留 JSON。

**文字被背景挡住？** 用 `Auto` 排序，或在列表里把文字行拖到最上面。
