# VM 图像缩放与对齐

[返回首页](../../../README.md) · [English](../../en/nodes/image-resize.md)

无需生成模型，可独立连接 Load Image 使用。

通常保持默认即可。如果图片太大、生成较慢或显存不足，可以减小处理尺寸。先选择缩放方式，再点击节点底部的“尺寸信息 / 缩放参数”，调整目标尺寸和算法。保持原尺寸时，这两个参数不生效。该面板也显示上次运行的尺寸信息。

| 设置 | 作用与建议 |
|---|---|
| **保持原尺寸** | 不主动缩放，适合先按原图尝试 |
| **按长边 / 宽度 / 高度缩放** | 按指定边调整大小，保持宽高比例 |
| **目标尺寸** | 指定所选边的像素数；例如按长边缩放到 1024 |
| **缩放算法** | 决定缩放时怎样处理细节，照片一般保持 `bicubic` 即可 |
| **整除数** | 让处理尺寸适配模型；本工作流建议保持 **32** |
| **语言** | 自动、中文或 English，可与编辑节点分别设置 |

算法速查：`bicubic` 适合一般照片；`area` 常用于缩小；`bilinear` 较平滑；`lanczos` 较锐利，但边缘可能出现光晕；`nearest-exact` 保留硬边，适合像素风格图片。

与 VM 图像编辑连接并传递尺寸上下文时，编辑最终输出会恢复到主图原尺寸；单独使用缩放节点则输出调整后的图像。缩小后再恢复尺寸不会还原已经丢失的细节，因此不宜为了速度把处理尺寸降得过低。


## 连线

输入 `image` 为原图；可选 `edit_mask` 与 `protect_mask` 必须对应同一原图尺寸。输出依次为处理后的图像、编辑遮罩、保护遮罩、尺寸上下文、尺寸信息。

与编辑节点组合时，将图像、遮罩和尺寸上下文一起连接到同一个编辑节点，避免混用不同来源。尺寸对齐会在右侧和下侧补边；它不等于向左右居中移动原图。

接入 Qwen Image 2.1 编辑时，最终工作图宽高都必须能被 32 整除，建议保持整除数为 32。其他整除数适合独立使用或其他下游节点；若最终尺寸不符合 Qwen 要求，编辑节点会提示错误。官方编码节点的 `resolution=0` 仍会对非 32 倍数图像取整缩放，不能代替统一的尺寸对齐。

独立缩放可处理单张 RGB 或 RGBA 图像，并保留第四通道；这不表示下游 VM 图像编辑会保留透明输出。
